## How to Capture

1. Start the application locally or via Docker
2. Complete a full provider onboarding flow
3. Log in as admin and review applications
4. Toggle dark mode and capture UI states
5. Open `http://localhost:5000/api/docs` for Swagger screenshot

Do not commit fabricated screenshots. Capture real screenshots from your running application.
